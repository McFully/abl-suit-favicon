# 06 Features

- **Generador de Prompts RSM:** Interfaz estructurada para definir estilo, nombre, fuentes y colores.
- **Eliminación de Fondo Local:** Procesa la imagen localmente para obtener transparencia RGBA.
- **Packager de Iconos:** Crea archivos `.ico` con resoluciones desde 16x16 hasta 256x256.
- **Assets para Instaladores:** Genera automáticamente los BMPs necesarios para Inno Setup, NSIS y WiX Toolset.
- **Asistente Paso a Paso:** Interfaz fluida que guía al usuario desde la configuración hasta la obtención de archivos.
- **Sistema de Auditoría:** Registro detallado de cada operación en logs locales.
