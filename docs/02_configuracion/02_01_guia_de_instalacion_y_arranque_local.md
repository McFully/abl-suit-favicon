# 02_01: Guía de Instalación y Arranque Local - ABL Suit Favicon

## 🚀 Requisitos del Sistema
- Windows 10/11 x64
- Python 3.10+ (Recomendado Python 3.13/3.14 x64)

## 🛠️ Instalación Paso a Paso

1. **Clonar o situarse en la carpeta del proyecto**:
   ```cmd
   cd "E:\Proyectos Antigravity\ABL Software\ABL Suit Favicon"
   ```

2. **Crear entorno virtual Python**:
   ```cmd
   python -m venv venv
   call venv\Scripts\activate
   ```

3. **Instalar dependencias requeridas**:
   ```cmd
   pip install -r requirements.txt
   ```

4. **Ejecutar la aplicación**:
   ```cmd
   python main.py
   ```
   O ejecutar el archivo `Lanzar_App.bat`.
